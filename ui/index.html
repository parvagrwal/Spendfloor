Try to break it (simulator)

Pick a spend and see what the vault would do. This runs entirely in your browser. No real transaction is sent, no keys are used, and nothing on-chain changes. The real vault enforces the same rules on-chain; this is the same policy, played with safely.

Simulated window state:

Spent 1 SFUSD  |  Headroom 4 SFUSD

Simulation starts from the live state (spent 1, headroom 4). An accepted simulated spend raises simulated spent; a rejected one leaves it unchanged. Reset restores the live state.

How it works

1.
An agent drafts a spend. A prompt injection can make it draft a drain to an attacker.
2.
The vault checks the policy on-chain: signer, recipient, caps, window. No app code stands between the draft and the chain.
3.
Bad spends revert. The attacker gets nothing, the policy reads back unchanged, and the attempt is on-chain evidence.
