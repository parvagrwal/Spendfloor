How it works

1.
An agent drafts a spend. A prompt injection can make it draft a drain to an attacker.
2.
The vault checks the policy on-chain: signer, recipient, caps, window. No app code stands between the draft and the chain.
3.
Bad spends revert. The attacker gets nothing, the policy reads back unchanged, and the attempt is on-chain evidence.
